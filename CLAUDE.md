# JEV-IMRP project rules

## Attribution

Never add a co-author attribution for an AI tool to commits, pull requests, or
versioned artifacts. All work is attributed to the human maintainer.

## Broker boundary

OpenAlgo is the active data-only gateway and must be pinned to the FYERS
connection for this project. Direct FYERS OAuth is an optional qualification
path, not a runtime prerequisite.

Do not add live order placement, hidden credential flows, silent provider
fallback, or unrecorded broker switching. Preserve Analyze-mode, finance,
security, testing, and authorship constraints. Historical provider labels in
immutable research artifacts are provenance and must not be rewritten.
